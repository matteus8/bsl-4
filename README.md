# BSL-4

A web dashboard that aggregates public environmental, orbital, and market feeds to show current global threat levels alongside contextual reality checks.

**Live site:** [platformstaq.com](https://platformstaq.com)

---

## What It Does

1. **Global Panic Index & Situation Overview**  
   A deterministic mathematical scoring algorithm in AWS Lambda evaluates ingested sensor metrics across all vectors to compute a repeatable 1–10 Panic Index score. Google Gemini is then prompted to write a concise narrative summary contextualizing the score.

2. **Regional Map & Proximity Scoring**  
   An interactive D3 world map displaying active M4.5+ earthquakes (USGS) and severe weather alerts (NOAA). Computes a deterministic local risk score based on physical distance (in kilometers) from the user's selected location.

3. **Space & Orbital Watch**  
   - **NASA NeoWs**: Ingests upcoming near-Earth asteroid approaches with flyby distances (km and lunar distances) and estimated diameters.  
   - **NASA DONKI**: Ingests solar flare classifications, geomagnetic storms (Kp-index), and coronal mass ejections.

4. **AI-Generated Social Claims & Debunks**  
   Simulated mock viral social media posts and accompanying reality checks generated by Google Gemini to illustrate common online doom claims against physical sensor data.

5. **Financial Volatility Snapshots**  
   Periodic price and percentage change snapshots of major global indices and commodities (VIX, S&P 500, FTSE 100, Nikkei 225, Gold, Bitcoin) fetched via Yahoo Finance.

6. **Event Telemetry Log**  
   A searchable, filterable log of ingested events displaying timestamps, geographic coordinates, severity scores, and reporting agency attribution.

## Data Sources

| Domain | Source | What Is Tracked |
| :--- | :--- | :--- |
| **Seismic** | USGS Earthquakes API | Earthquakes magnitude 4.5+ worldwide |
| **Severe Weather** | NOAA / Weather.gov | Active storm, blizzard, and severe weather warnings |
| **Space Weather** | NASA DONKI | Solar flares, geomagnetic storms, CME activity |
| **Asteroids** | NASA NeoWs | Upcoming close approaches, miss distances, hazard flags |
| **Financial** | Yahoo Finance (`yfinance`) | Periodic index and volatility snapshots |
| **Geocoding** | Open-Meteo & OpenStreetMap | City-to-coordinate lookups for proximity calculations |

## Tech Stack

- **Frontend**: Next.js (Static Export), React, TypeScript, Tailwind CSS, D3-geo, Lucide Icons
- **Backend & Cloud Workers**: AWS Lambda (Python 3.12 serverless compute), Amazon EventBridge (cron triggers), Amazon S3, Amazon CloudFront (Edge CDN), Google Gemini (Structured Output), Supabase (PostgreSQL)
